# Task Management System (Laravel Project)

## Description
This is a Task Management Web Application built using Laravel.  
The system allows users to create, update, and manage tasks.  
It includes authentication, role-based access control, and task tracking features.

---

## Technologies Used
- Laravel 12
- PHP 8
- MySQL (XAMPP)
- Blade Template Engine
- Tailwind CSS
- Laravel Breeze (Authentication)
- Node.js & npm

---

## Setup Instructions

1. Clone the repository:
   git clone https://github.com/tebogomakgato26/task-manager.git

2. Navigate into the project:
   cd task-manager

3. Install PHP dependencies:
   composer install

4. Install frontend dependencies:
   npm install

5. Run the application:
   php artisan serve

6. Run frontend:
   npm run dev

---

## How to Use

- Register a new user account  
- Login using your credentials  
- Create new tasks  
- Edit or delete tasks  
- Assign tasks to users  
- Update task status (Pending, Completed, etc.)

---

## Features

- User authentication (Login/Register)
- Task creation and management
- Task categories and priorities
- Role-based access control
- Responsive user interface

---

## Database

The system uses MySQL.  
Migrations are included to automatically create database tables.
